# `cart/`

> السلة — «ما ينوي العميل شراءه»

| | |
|---|---|
| **الطبقة** | L5 |
| **يعتمد على** | access · pricing · inventory · catalog · core |
| **الحالة** | مكتمل — المرحلة ٥ |

## المسؤوليات

Cart · CartLine · دمج سلة الزائر · إعادة تحقق كاملة

## القرار المحوري

**لا أسعار مخزَّنة.** السعر يُحسب من `pricing` عند كل عرض — تخزينه يعني سلة تعرض سعر الأمس.

## الحدود

الواجهة العامة الوحيدة هي **`services.py`**. النطاقات الأخرى تستدعي
الخدمات ولا تلمس `models.py` مطلقًا — يفرضه `import-linter` في الـ CI.
