# ١. الاستجابة لكل الشاشات والمقاسات

> **مبدأ:** لكل بوابة جهاز أساسي مختلف. **تصميم واحد يناسب الجميع = تصميم لا يناسب أحدًا.** (ADR-20)

| البوابة | الجهاز الأساسي | النهج |
|---|---|---|
| **Store** | الهاتف | Mobile-first — الطلاب يتسوقون من الهاتف |
| **Customer** | الهاتف | Mobile-first |
| **POS** | التابلت أفقيًا | Tablet-first · أهداف لمس ≥ ٤٤px · بلا تمرير أفقي |
| **Employee** | التابلت / اللابتوب | متوازن |
| **Admin** | اللابتوب / الشاشة الكبيرة | Desktop-first مع بقائه صالحًا على التابلت |

## نقاط الكسر الموحّدة

```scss
$bp: (
  xs:  0,        // هاتف رأسي
  sm:  576px,    // هاتف أفقي
  md:  768px,    // تابلت رأسي
  lg:  992px,    // تابلت أفقي / لابتوب صغير
  xl:  1200px,   // ديسكتوب
  xxl: 1400px,   // شاشة كبيرة
);
```

موروثة من Bootstrap 5 المستخدم في قالب Greeny. **لا تُخترع نقاط كسر جديدة.**

## القواعد الملزمة

| # | القاعدة |
|---|---|
| 1 | **Mobile-first** — الأنماط الأساسية للهاتف، والتوسيع بـ `min-width` فقط. لا `max-width` إلا استثناءً مبررًا |
| 2 | **وحدات نسبية** — `rem` · `%` · `clamp()`. ممنوع `px` للأبعاد التخطيطية |
| 3 | **الجداول** داخل حاوية `overflow-x: auto`. **الصفحة نفسها لا تتمرر أفقيًا أبدًا** |
| 4 | **جداول الأدمن على الهاتف** تتحول إلى بطاقات، لا جدول مضغوط |
| 5 | **الصور** — `next/image` + أحجام متجاوبة + `max-width: 100%` |
| 6 | **اللمس** — أي عنصر تفاعلي ≥ ٤٤×٤٤px على الأجهزة اللمسية |
| 7 | **الاختبار** — كل شاشة تُتحقق على **٣٦٠px · ٧٦٨px · ١٢٨٠px · ١٩٢٠px** قبل اعتبارها منجزة |

## تحوّل التنقل

| العنصر | ديسكتوب | موبايل |
|---|---|---|
| التبويبات الرئيسية | أفقية كاملة | قابلة للتمرير أفقيًا |
| الشريط الجانبي الداخلي | ثابت جانبًا | Drawer أو قائمة منسدلة |
| الجدول الكثيف | جدول كامل | بطاقات أو تمرير أفقي داخل حاوية |
| النموذج الكبير | أقسام أو تبويبات | Stepper |
| الإجراءات | أزرار ظاهرة | قائمة سياقية |
| القائمة العامة | شريط جانبي ثابت | Drawer بزر hamburger |

**التسلسل المعلوماتي يبقى واضحًا في كل المقاسات.**

# ٢. RTL / LTR

| القاعدة | التفصيل |
|---|---|
| **الاتجاه من الجذر** | سمة `dir` على العنصر الجذر — **لا يُثبَّت في أي مكوّن** |
| **خصائص منطقية** | `margin-inline-start` لا `margin-left` · `padding-inline-end` لا `padding-right` |
| **الحدود والزوايا** | `border-inline-start` · `border-start-start-radius` |
| **Flexbox/Grid** | `flex-direction: row` ينعكس تلقائيًا — لا حاجة لتجاوز |
| **الأيقونات الاتجاهية** | الأسهم تنعكس · الأيقونات الرمزية لا |
| **الأرقام والتواريخ والعملة** | `Intl` مع الـ locale — لا تنسيق يدوي |

## ⚠️ تغيير عن الوضع الحالي

المشروع الحالي ينسخ القالب مرتين: `static/ar/` (RTL) و `static/en/` (LTR)، ويبدّل بينهما في `templates/base.html:37-57`.

**هذا يُلغى.** Bootstrap 5.3 يدعم RTL أصلًا، والخصائص المنطقية تُغني عن نسختين. **نسخة أنماط واحدة + سمة `dir`.**

# ٣. نظام الثيم القابل للتحكم من الأدمن

> **المتطلب:** التحكم في الألوان واللوجو والشعارات وكل شيء **من لوحة الأدمن** — بلا إعادة نشر.

## التدفق

```text
GET /api/v1/branding/          ← عام · مُخزَّن بقوة
        ↓
Next.js Root Layout (Server Component)
        ↓
حقن <style> بمتغيرات CSS في :root      ← SSR · لا وميض ألوان (ADR-23)
        ↓
كل المكوّنات تستخدم var(--color-primary)
```

## ⚠️ قيد حاسم على نقل قالب Greeny

قالب Greeny يستخدم متغيرات **Sass** — وهي **تُحسم وقت البناء**.

```scss
/* ❌ الخطأ — التحكم من الأدمن مستحيل دون إعادة بناء */
$primary: #4caf50;
.btn-primary { background: $primary; }

/* ✅ الصحيح — قابل للتغيير وقت التشغيل */
:root {
  --color-primary: #4caf50;        /* قيمة ابتدائية، تُستبدل من الـ API */
}
.btn-primary { background: var(--color-primary); }
```

> **التحويل يجب أن يحدث أثناء نقل SCSS في المرحلة ١.٥، لا بعده.** (ADR-22)
>
> لو نُقل القالب بألوان Sass ثابتة، يصير التحكم من الأدمن **مستحيلًا**، وتُعاد كتابة كل الأنماط لاحقًا.

## رموز التصميم

```scss
:root {
  /* الألوان — تُحقن من branding API */
  --color-primary: ...;      --color-secondary: ...;   --color-accent: ...;
  --color-success: ...;      --color-warning: ...;     --color-danger: ...;
  --color-info: ...;
  --color-bg: ...;           --color-surface: ...;     --color-border: ...;
  --color-text: ...;         --color-text-muted: ...;

  /* الخطوط — تُحقن من branding API */
  --font-ar: ...;            --font-en: ...;           --font-size-base: ...;

  /* الشكل — تُحقن من branding API */
  --radius: ...;             --shadow-level: ...;

  /* المسافات — ثابتة، غير قابلة للتحكم */
  --space-1 … --space-12;
}
```

**المسافات ونقاط الكسر ليست قابلة للتحكم من الأدمن.** تغييرها يكسر التخطيط. القابل للتحكم: الألوان والخطوط واللوجو والشكل.

## الوضع الفاتح والداكن

```scss
:root                                  { /* الفاتح — كل الرموز */ }
:root:not([data-theme="light"]) {
  @media (prefers-color-scheme: dark)  { /* الداكن */ }
}
:root[data-theme="dark"]               { /* الداكن — تبديل صريح */ }
```

كلا الوضعين يأتيان من `branding` — الأدمن يضبط لوحتين.

## قواعد إضافية

- **معاينة حية قبل الحفظ** — لا يُطبَّق التغيير على المستخدمين قبل التأكيد
- **فحص التباين** (WCAG AA) وتحذير الأدمن عند اختيار مجموعة غير مقروءة
- **رفع اللوجو**: فحص نوع وحجم وأبعاد
- **كل تغيير يمر بـ `AuditLog`**
- ألوان Greeny الافتراضية تبقى كقيم ابتدائية

# ٤. نقل قالب Greeny

## ما يُعاد استخدامه فعليًا

| العنصر | المصير |
|---|---|
| **SCSS** (`1-helpers` … `5-pages`) | ✅ **REUSE** — نظام التصميم: التايبوغرافي · المسافات · الأزرار · الكروت · الفورمز. **يوفّر ٣-٤ أسابيع** |
| بنية HTML للصفحات | 📖 **REFERENCE** — مرجع بصري يُترجم إلى JSX |
| jQuery plugins | ♻️ **REBUILD** — بدائل React |
| بنية `static/ar` + `static/en` المزدوجة | ♻️ **REBUILD** — نسخة واحدة + `dir` |
| `templates/base.html` | ❌ **DELETE** |

## استبدال المكوّنات

| القالب | البديل |
|---|---|
| `slick` (سلايدر) | Embla أو Swiper |
| `isotope` (فلترة شبكية) | CSS Grid + فلترة من الخادم |
| `venobox` (lightbox) | مكوّن lightbox حديث |
| `nice-select` | Select قابل للوصول (headless) |
| `countdown` | Hook بسيط |

**كلها بلا jQuery.**

## خطوات النقل (المرحلة ١.٥)

```text
1. انسخ بنية SCSS من static/en/scss  (LTR — المصدر الأنظف)
2. حوّل كل $color إلى --color-*  في :root    ← إلزامي
3. استبدل الخصائص الاتجاهية بالمنطقية        ← يلغي الحاجة لنسخة RTL
4. احذف كل CSS خاص بـ jQuery plugins
5. ابنِ shared/ui فوق الرموز الناتجة
6. ابنِ shared/layouts الثمانية
7. تحقق: تغيير --color-primary من الأدمن ينعكس فورًا
```

# ٥. إمكانية الوصول

| البند | المطلوب |
|---|---|
| التباين | WCAG AA حدًّا أدنى — يُفحص آليًا عند تغيير الثيم |
| لوحة المفاتيح | كل عنصر تفاعلي قابل للوصول بالتاب · ترتيب منطقي · مؤشر تركيز ظاهر |
| قارئات الشاشة | HTML دلالي · `aria-label` حيث لا يوجد نص · مناطق حية للإشعارات |
| النماذج | كل حقل له `label` مرتبط · الأخطاء مرتبطة بحقولها |
| الصور | `alt` وصفي · فارغ للصور الزخرفية |
| الحركة | احترام `prefers-reduced-motion` |
| اللغة | سمة `lang` صحيحة — مهمة لنطق قارئ الشاشة بالعربية |

# ٦. بوابة الجودة البصرية

قبل اعتبار أي شاشة منجزة:

- [ ] مُختبَرة على ٣٦٠px · ٧٦٨px · ١٢٨٠px · ١٩٢٠px
- [ ] لا تمرير أفقي للصفحة في أي مقاس
- [ ] تعمل في RTL و LTR
- [ ] تعمل في الوضع الفاتح والداكن
- [ ] تحترم رموز الثيم — **صفر لون مكتوب يدويًا**
- [ ] تستخدم تخطيطًا من `shared/layouts/`
- [ ] أهداف اللمس ≥ ٤٤px على الأجهزة اللمسية
- [ ] قابلة للتصفح بلوحة المفاتيح
- [ ] حالات فارغة وتحميل وخطأ مُصمَّمة — لا شاشة بيضاء
