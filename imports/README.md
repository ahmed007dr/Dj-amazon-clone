# `imports/`

> الاستيراد الجماعي للكتالوج من ملف إكسل

| | |
|---|---|
| **الطبقة** | فوق نطاقات العمل، تحت `ops` |
| **يعتمد على** | `catalog` · `inventory` · `access` · `core` |
| **يعتمد عليه** | `ops` وحده — لاستئناف الوظائف المتروكة |
| **مثبّت في الإنتاج** | ✅ نعم |

## لماذا تطبيق منفصل؟

ملف واحد يُنشئ `catalog.Product` ويستلم رصيده الافتتاحي عبر
`inventory.services.receive` — و`inventory` **فوق** `catalog`.

فوضعه في `catalog` يجعله يستورد الطبقة التي فوقه، ووضعه في `inventory`
يجعل المخزون يملك محلّل جداول. مكانه الطبقة الموجودة أصلًا لهذا الغرض:
عمل عابر للنطاقات لا يستورده أحد — نفس تبرير `ops` و`seo` و`reporting`.

وهو **تحت `ops` لا بجانبه**: المحاولة الأولى وضعته بجانبه، ورفضها
`import-linter` في سطر واحد — الإخوة لا يستورد بعضهم بعضًا، و`run_periodic`
مضطرّ أن ينادي `resume_abandoned`. الطبقة الأدنى تصف العلاقة الحقيقية:
`ops` هو المشغّل، و`imports` أحد ما يشغّله.

## ⚠️ لا طابور — القطعة هي وحدة العمل

لا Celery (ADR-42)، و Passenger يقتل الطلب الطويل. فوحدة العمل **قطعة**:
اقرأ من المؤشر، نفّذ بضع مئات من الصفوف في معاملة واحدة، اكتب العدّادات،
ارجع. من ينادي بعدها يكمل من حيث توقّف هذا بالضبط.

ثلاثة منادين، وكلهم متكافئون:

```
متصفّح الأدمن   →  حلقة على POST .../advance/     (تقدّم حيّ)
run_periodic     →  شبكة أمان للوظائف المتروكة
manage.py        →  الطرفية، للتحميل الأول الكبير
```

و**كل قطعة تُودَع وحدها**. معاملة واحدة حول عشرة آلاف صف تحتجز أقفالًا على
عشرة آلاف منتج بينما المتجر يبيعها، وتتراجع عن أربع دقائق من العمل لأن
الصف ٩٨٨٠ فيه تاريخ خاطئ. الإيداع لكل قطعة يعني نتيجة جزئية — وهي حالة
يسمّيها النموذج (`PARTIAL`) لا حادثة.

## دورة الحياة

```
رفع ──► UPLOADED
  │
  ├─ فحص جاف ──► VALIDATING ──► VALIDATED   (لا يُكتب شيء)
  │                          └► REJECTED    (خطأ واحد يكفي)
  │
  └─ تنفيذ    ──► RUNNING    ──► DONE
                             └► PARTIAL
```

`VALIDATED` **ليست نهائية ولا جارية** — هي وقفة ينتظر فيها النظام قرار
الأدمن. ولهذا حلقة العميل شرطها `is_running` لا `!is_terminal`؛ الثانية
تدور عند الوقفة إلى الأبد.

ولا تنفيذ إلا من `VALIDATED`. الفحص الجاف يكلّف مرورًا واحدًا على ملف
سيُمرَّر عليه ثلاث مرات، وهو اللحظة الوحيدة التي يكون فيها الخطأ مجانيًا.
السماح بالتنفيذ من `UPLOADED` يجعله اختياريًا — وخطوة أمان اختيارية على
عشرة آلاف صف هي خطوة لا يفعلها أحد.

## المراحل — والترتيب مقصود

`PRODUCTS → VARIANTS → STOCK`

سطر المخزون يسمّي منتجه بالرمز، والنسخة تسمّي أصلها كذلك. استلام مخزون
قبل وجود المنتج هو غلطة الترتيب الوحيدة التي لا يُصلحها إعادة التشغيل —
الدفعة يجب أن تتعلّق بشيء.

وحجم القطعة يختلف بالمرحلة: ٥٠٠ للمنتجات (إدراج جماعي)، و٢٠٠ للمخزون —
لأن `receive` يأخذ `select_for_update` ويكتب دفعة وحركة وفحص تنبيهات لكل
سطر: خمسة استعلامات وقفل محجوز لكل واحد.

## ⚠️ المخزون يدخل عبر `inventory` وحده

الكتابة المباشرة في `Stock.quantity_physical` أسرع مئة مرة وتنتج مخزونًا
لا يحاسبه أحد: بلا `Batch` فبلا صلاحية وبلا تكلفة، وبلا `StockMovement`
فالسجل والرصيد يختلفان من أول سطر. `suppliers` يحمل نفس التحذير بكلماته.

## ⚠️ لا يُنشَر شيء تلقائيًا

كل ما يستورده يدخل بـ`is_active=False`. ظهور عشرة آلاف منتج في المتجر
لحظة انتهاء الاستيراد ليس استيرادًا سريعًا بل انقطاعًا بكتالوج ملحق به.
النشر ضغطة ثانية مستقلة بعد المراجعة.

## الملفات

|---|---|
| `spec.py` | مواصفة الأعمدة — **مصدر واحد** للقالب والقارئ والمحقّق والواجهة |

| `validators.py` | التحقق — يستخدمه الفحص الجاف والتنفيذ معًا |
| `services.py` | دورة الحياة والقطع |
| `report.py` | ملف الصفوف الفاشلة |

## الأوامر

```bash
python manage.py run_import catalogue.xlsx --mode CREATE_ONLY
python manage.py run_import catalogue.xlsx --validate-only     # يعيد ١ عند الرفض
python manage.py run_import --job <uuid> --resume
python manage.py run_import --list
python manage.py run_import catalogue.xlsx --publish --errors-to errors.xlsx
```

و`--validate-only` يعيد رمز خروج غير صفري عند الرفض، فيصلح بوابة في خط نشر.

## الجدولة

`resume_imports` مضافة إلى `run_periodic` كمجموعة `imports`. تُقدّم كل
وظيفة متروكة **قطعة واحدة لكل نبضة** لا حتى النهاية: تشغيلها للنهاية يجعل
الأمر الدوري يستغرق دقائق ويحجز الطابور خلفه — وطابور البريد مجدول كل بضع
دقائق لسبب.

المتروك = `RUNNING` أو `VALIDATING` ونبضته أقدم من ثلاث دقائق. ليست مهلة
على العمل — القطعة تستغرق ثوانٍ — بل تمييز «الأدمن يقود هذا الآن» عن
«الحاسوب أُغلق عند الصف أربعة آلاف».
