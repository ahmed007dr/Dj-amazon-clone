# `notifications/`

> الإشعارات متعددة القنوات

| | |
|---|---|
| **الطبقة** | مستهلك فقط |
| **يعتمد على** | كل النطاقات — بالاستماع |
| **الحالة** | مكتمل — المرحلة ٦ |

## المسؤوليات

Notification · NotificationPreference · NotificationLog · المستمعون

## القرار المحوري

**لا نطاق يستورد هذا النطاق** — يفرضه عقد `notifications-isolated`. النطاقات تبعث إشارات وهذا يستمع؛ الاستدعاء المباشر يعني أن `inventory` يعرف بوجود البريد.
