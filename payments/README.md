# `payments/`

> سجل بوابات قابل للضبط من الأدمن

| | |
|---|---|
| **الطبقة** | L7 |
| **يعتمد على** | orders · customers · core |
| **الحالة** | مكتمل — المرحلة ٥ |

## المسؤوليات

PaymentProvider · ProviderCredential · PaymentTransaction · Refund · WebhookEvent

## القرار المحوري

**لا بوابة مثبتة في الكود.** إضافة بوابة = محوّل + صف في السجل — بلا مساس بأي نطاق آخر (ADR-15).

## الأحداث الواردة

```
POST /api/v1/payments/webhooks/<رمز البوابة>/
```

بلا مصادقة — **التوقيع هو الهوية**. يُسجَّل العنوان في لوحة كل بوابة.

- الحدث المزوَّر يُرفض ولا يدخل `WebhookEvent` (تسجيله كان يسمح بحجز
  معرّف الحدث الحقيقي فيُهمَل).
- التكرار يُقاس بالمعالجة لا بالتسجيل — الفشل المؤقت يُعاد تطبيقه.
- المبلغ الوارد يُقارَن بمبلغ المعاملة قبل تعليمها مدفوعة.

النتيجة تُعلَن بإشارة في `events.py`؛ و`payments` لا يستورد `orders`
ولا يعلّم طلبًا بنفسه — الطبقات تمنعه.

## بيانات الاعتماد

`ProviderCredential.value` **مشفّرة في قاعدة البيانات** عبر
`core.encryption` و`FIELD_ENCRYPTION_KEY`. لا تُقرأ عبر أي API، ولا
يُستعلَم عنها (التشفير عشوائي فالمقارنة تفشل دائمًا).

## الحدود

الواجهة العامة الوحيدة هي **`services.py`**. النطاقات الأخرى تستدعي
الخدمات ولا تلمس `models.py` مطلقًا — يفرضه `import-linter` في الـ CI.
