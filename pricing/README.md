# `pricing/`

> محرك التسعير — «كم يدفع هذا العميل؟»

| | |
|---|---|
| **الطبقة** | L3 |
| **يعتمد على** | catalog · accounts · core |
| **الحالة** | مكتمل — المرحلة ٥ |

## المسؤوليات

PriceList · PriceRule بأسعار كميات · PriceOverride ترويجي · حساب الضريبة

## القرار المحوري

يستبدل **أربعة** مواضع حساب متعارضة في الكود القديم (H5). `price_for()` هو المصدر الوحيد — السلة والطلب ونقطة البيع كلها تستهلك نتيجته.

## الحدود

الواجهة العامة الوحيدة هي **`services.py`**. النطاقات الأخرى تستدعي
الخدمات ولا تلمس `models.py` مطلقًا — يفرضه `import-linter` في الـ CI.
